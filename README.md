#  JavaScript Phase — Complete 

My JavaScript learning journey in code: **15+ small projects** built to get fluent in the language before moving on to TypeScript, React and cross-platform apps (web, mobile, desktop).

This repo marks the end of **Phase 1 (JavaScript fundamentals)** on my roadmap.

---

## What this repo covers

Small, focused programs written to build core JavaScript fluency:

- **Language basics:** syntax, variables, functions, arrays and objects
- **DOM manipulation:** building interactive pages with plain JavaScript
- **Event handling:** responding to clicks, input and timers
- **Working with APIs:** fetching and displaying data from external sources
- **DSA practice:** algorithms and data structures (Fisher-Yates shuffle, hash maps)
